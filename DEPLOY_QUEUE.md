- **NEW: Visual Hero Rule** added to `docs/visual-patterns.md` as a global principle. Every visual's hero element must lead with the compelling question the visual is answering — not a context label, not a budget banner, not a category eyebrow. - **NEW: Source Placement Rule** added to `docs/visual-patterns.md` as a global principle. Source attribution must live both structurally inside the Schema.org wrapper AND visually bound to the visual block — never as a floating paragraph below. Two failure modes prevented: structural drift (citation outside the `itemscope` wrapper, parser doesn't bind it) and visual detachment (source doesn't travel when visual gets scraped as image). Best practice: bound footer row with `#f8f9fa` background, flat top border, shared bottom-radius with visual, INSIDE the wrapper. For SVG patterns, source ALSO baked into SVG `<text>` for image-scrape survival. Per-pattern source-row requirements documented for all 7 patterns.
